# 任务状态模型

## 会话状态

`输入` → `待确认` → `查询中` → `已完成` / `部分完成` / `无匹配` / `异常` → `已停止` 或 `新轮次`

## 组合状态

每个目的地 × 出发机场 × 日期组合必须有且只有一个可追踪状态：

- `未开始`
- `查询中`
- `已完成`
- `失败`
- `受到限流`
- `超时`
- `无匹配`

用户询问进度只读取当前状态，不改变任务；用户停止后不得创建新的搜索调用；用户修改条件后必须形成新条件版本并重新确认。

任务状态模块通过 `getProgress(task)` 只读汇总进度，通过 `stopSearchTask(task)` 停止任务，并由 `canStartNextCall(task)` 阻止停止后的新调用。
