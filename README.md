# 机票酒店小助手 Agent

这是一个“机票酒店小助手”的 P0 Agent 工作区，支持多模态输入、航班/酒店精准核验、候选比较、替代搜索和官方详情交接。

## 架构

- `runtime/`：Agent 身份、Skills、状态规则、工具契约和非密钥配置。
- `eval/`：Test Journey、Ground Truth、测试用例和受控结果。
- `evidence/`：Bad Case、走查记录和修复证据。
- `use-cases/`：核心使用场景。

整体采用一个 Agent 编排多模态识别、条件确认和工具调用；机票使用飞猪查询，酒店当前使用 RollingGo 查询，时间推算和详情交接通过独立工具完成。

## 当前阶段

P0 使用受控测试数据，不接真实航班或酒店库存、购票、支付、改订、取消或后台监控。当前仓库只保存 Agent 规则、Skills、工具契约、评测材料和证据记录。

## 本地检查

需要 Node.js 18 或更高版本。在仓库根目录执行：

```bash
node --test runtime/tools/*.test.mjs
```

当前运行层使用受控测试实现，不代表真实库存、价格或最终可购买性。

## 安全说明

真实供应商凭证必须通过环境变量注入，不要写入仓库。请勿提交 API Key、Cookie、日志、临时附件或个人信息。本项目不包含支付、下单、改订或取消能力。
