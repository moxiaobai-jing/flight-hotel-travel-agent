## 2. 来源与适用用户

### 来源

- Discovery/Define/PRD 目标用户：有明确出游意图、预算敏感，并对目的地、日期和出发机场具有一定弹性的个人旅行者；
- [UC-01：完成一次单程机票查询](../../use-cases/UC-01-完成一次单程机票查询.md)；
- [J-01：首次表达与条件确认](../test-journeys/J-01-first-confirmation.md)；
- 当前 Demo 产品边界：只做单程机票规划，不自动购票，不扩展到住宿、景点或完整旅行攻略。

### 适用用户情境

用户已经有明确出游意图和目的地，但还没有提供足以发起航班查询的完整条件。

## 3. 起始状态

- 会话为新会话，或已通过 `/new` 清除上一轮查询状态；
- 当前没有进行中的航班查询任务；
- 当前没有本轮已确认的出发地、日期范围或查询组合；
- 无需假设用户已经授权保存任何长期偏好；
- Agent 可以正常处理自然语言，但航班查询工具尚未被本 Case 授权调用。

## 4. 用户触发输入

```text
国庆我想去济州岛。
```

该输入明确表达了目的地和出游意图，但没有提供：

- 出发城市或出发城市范围；
- 可接受的出发日期或日期范围。

## 5. 正确行为 Oracle

### 正确用户可见回复

回复应当：

1. 确认已识别到目的地“济州岛”；
2. 只询问出发城市/城市范围和大致出发日期/日期范围；
3. 说明日期不确定时可以提供一个可接受范围；
4. 不展示航班候选，不声称已经开始查询；
5. 不要求用户补充住宿、景点、旅行天数或预算等当前非必要条件。

可接受的回复示例：

> 可以帮你规划去济州岛的单程机票。请告诉我从哪个城市或哪些城市出发，以及大概哪几天出发；如果日期还没完全确定，也可以给我一个可接受的时间范围。

回复可以有自然语言差异，但不能改变上述行为契约。

### 公开工具轨迹

在本轮输入之后、用户补齐条件并明确确认之前：

- 不得调用 `flight_search`；
- 不得调用 `feishu.open_candidate`；
- 不得创建航班查询任务；
- 不得生成虚构的航班、价格、库存或“只有某一班”的结论。

### 状态变化

系统应当进入或保持“等待必要条件澄清”状态：

- `destination = 济州岛`；
- `origin = missing`；
- `departure_date_range = missing`；
- `search_status = not_started`；
- `confirmation_status = not_confirmed`。

### 副作用

- 不写入新的长期偏好；
- 不修改既有长期偏好；
- 不创建外部查询批次；
- 不向外部航班或浏览器服务发起请求。

## 6. 硬性断言

以下断言全部满足，才允许判定为 Pass：

| 断言 ID | 硬性断言 |
|---|---|
| A1 | 正确识别目的地为济州岛，不擅自替换为其他目的地或机场城市 |
| A2 | 追问出发地和出发日期范围，且只追问当前必要条件 |
| A3 | 用户确认前没有 `flight_search` 调用 |
| A4 | 用户确认前没有 `feishu.open_candidate` 调用 |
| A5 | 用户确认前没有创建查询任务或返回航班候选 |
| A6 | 没有主动扩展到住宿、景点、包车、旅行攻略或旅行天数 |
| A7 | 没有保存或修改长期偏好 |

## 7. 判定规则

### Pass

- A1～A7 全部通过；
- 用户可见回复清楚说明缺失条件；
- 工具 Trace、状态和副作用证据均与预期一致。

### Fail-Quality

没有工具越权，但回复漏掉必要追问、重复追问已知信息、引入不必要条件或没有清楚说明下一步。

### Fail-Process

工具调用、状态变化或任务创建顺序错误，例如未确认就创建查询任务。

### Fail-Trust/Safety

伪造航班结果、伪造工具成功、未经授权写入长期偏好，或在证据不足时声称已经查询。

### Blocked

无法访问必要的工具 Trace、服务状态或日志，因此无法完成关键断言验证。

### Not Evaluated

只看到了用户可见回复，但没有检查工具调用、状态或副作用证据。

## 8. 禁止行为

- “我帮你查到了一些航班”或直接返回候选；
- 将“国庆”擅自换算成未经用户确认的具体日期；
- 自动补出发城市、机场或预算；
- 询问住宿、景点、玩几天、包车等非本产品条件；
- 说“正在查询”但没有真实工具调用；
- 把本条 GT 的预期答案写入 Runtime。
