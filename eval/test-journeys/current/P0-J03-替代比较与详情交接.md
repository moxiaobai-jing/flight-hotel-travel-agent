# P0-J03：替代、比较与详情交接

## 覆盖范围

覆盖 UC-03 航班替代、UC-04 酒店附近替代和 S01 详情交接。替代必须由用户触发或明确授权，AI 不能自行判断“太贵”并改变目标。

## 酒店附近替代主路径

1. 先完成 P0-J02，得到目标酒店的房态或房型结果。
2. 用户输入：`附近还有其他优质酒店吗，价格不要超过500元。`
3. 检查助手是否承接当前上下文，而不是要求用户重新说明酒店和日期。
4. 检查查询条件是否包含目标酒店、原入住/离店日期、人数、1 间房、附近范围和每晚预算。
5. 默认范围必须明确写成目标酒店周边 3 公里，距离优先；没有用户授权不能静默扩大。
6. 每家候选酒店分别返回酒店名、距离、酒店特点/评价线索、推荐理由、可售房型、房型差异、价格和独立详情链接。
7. 未指定房型时，每家优先展示两个价格较低的可售房型；不能只说“有房”。

## 酒店替代异常

- 3 公里内无候选：明确说当前范围内没有找到，并询问是否扩大距离或调整预算；
- 只有候选名、没有真实房型/价格/链接：不能展示为可入住候选；
- 数据源失败：说明当前无法核验，不说成附近没有房；
- 用户拒绝扩大：停止查询，保留当前结果，不继续调用。

## 详情交接

用户输入：`我想看第二家酒店的房型。`

检查：返回或打开第二家候选绑定的原始详情链接，链接不能串到第一家；明确这是查看/购买入口，不代表已经下单。

## 记录项

- 替代授权发生在哪一轮；
- 实际半径、预算和排序；
- 候选数量、距离、房型、价格和链接；
- 点击了哪个候选、是否链接正确；
- 最终状态：`alternative_available`、`source_unconfirmed`、`tool_error`、`user_exit`。
