# P0-J01：航班同款核验与替代

## 覆盖范围

覆盖 UC-01 航班同款核验和 UC-03 航班替代；继续复用旧版 Flight Planning 的自然语言搜索能力和 V1.0 结果字段，但由机票酒店小助手统一入口承接图片、文字和确认状态。

## 主路径：航班号缺失时精确匹配

1. 发送航班截图，确保能识别出日期、出发地、目的地、出发时间和抵达时间，但航班号模糊或缺失。
2. 检查助手是否说明将按日期、机场、出发时间和抵达时间完全一致查询；不能把前后相近时间当成同款。
3. 用户输入：`可以，按这个查。`
4. 检查工具是否只在确认后调用。
5. 如果命中多个候选，逐条返回航班号；每条保留 V1.0 字段：候选、航班号、价格、日期、路线、出发时间、抵达时间、飞行时长、总耗时、直达和点击详情。

## 替代分支

1. 精确条件没有候选时，助手必须明确说没有找到航班号一致或时间完全一致的航班。
2. 助手提出默认前后 3 小时，并说明价格优先；不能直接扩大。
3. 用户输入：`可以，直飞优先，价格从低到高。`
4. 检查仅在用户确认替代范围后查询；直飞结果按价格排序；每个候选仍保留 V1.0 字段和独立详情链接。
5. 用户说“前后一天”时，检查日期扩大再次经过用户确认，并明确标记日期变化。

## 红线

- 航班号缺失不能阻断，但时间匹配必须完全一致；
- 用户未授权不能扩大时间范围；
- “价格不要太高”不等于 AI 自行设定金额上限；
- 不把替代航班说成同款，不执行购票、支付、改签或取消。
