# P0-J00：统一入口与参考材料

## 目的

验证“机票酒店小助手”进入新会话后的 onboarding、自然语言输入、航班/酒店图片输入和无法识别兜底。对象或必要字段不完整时不得调用查询工具。

## 测试步骤

### 1. onboarding

输入：`/new`

检查：欢迎语同时说明可以查询机票和酒店；没有创建航班或酒店工具调用；进入 `onboarding_shown`。

### 2. 自然语言机票意向

输入：`我想从杭州去成都，9月28日找一张机票。`

检查：识别为机票；按旧版 Flight Planning 规则追问或确认必要条件；用户确认前不返回正式候选。

### 3. 航班截图或文字

发送航班截图，补充：`帮我找这张图里的同款。`

检查：提取日期、出发地、目的地、出发时间、抵达时间和可选航班号；缺字段时只追问影响核验的字段。

### 4. 酒店截图或文字

发送酒店截图，补充：`帮我查这家酒店。`

检查：提取酒店中文名、英文名/别名和地址；缺入住或离店日期时追问；人数未提供时按 1 位成人、1 间房进入确认信息。

### 5. 无关图片或文字

发送与航班、酒店无关的图片，或输入：`帮我看看这个。`

必须返回统一兜底：未识别到可用于查询的航班或酒店信息，并引导用户发送航班/酒店截图、名称、日期或具体查询意图。不得描述无关图片内容，不得调用航班或酒店工具。

## 记录项

- 实际回复和是否有人情味；
- 提取字段、缺失字段和默认字段；
- 工具调用数量及名称；
- 状态：`onboarding_shown`、`awaiting_clarification` 或 `unsupported_input`；
- 最终判定：通过 / 不通过 / 未验证。
