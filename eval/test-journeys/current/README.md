如果需要查看完整的细分节点、状态、扩展路径和对话示例，请先看：[详细节点、状态与对话示例索引](./详细节点-状态-对话示例索引.md)。

## Journey 与 Use Case 对照

| 当前 Test Journey | 覆盖内容 | 重点 |
|---|---|---|
| P0-J00 | C01 | onboarding、图片/文字输入、无法识别兜底、最小追问 |
| P0-J01 | UC-01、UC-03 | 航班同款、航班号缺失时精确时间匹配、航班替代 |
| P0-J02 | UC-02 | 酒店日期和人数确认、全部可售房型、房态状态、详情链接 |
| P0-J03 | UC-04、S01 | 附近酒店、3 公里默认范围、价格/距离、房型和查看详情 |
| P0-S01 | C02、PS-05、PS-06 | 无法核验、工具失败、重试、修改条件、退出 |

每条路径都记录：用户原始输入、Agent 回复、工具调用、查询条件、状态变化、详情链接和最终判定。没有观察到的内容写“未验证”。

`../J-01` 到 `../J-08` 是旧版 Flight Planning 的兼容回归材料，不属于本次机票酒店小助手的主测试入口。
