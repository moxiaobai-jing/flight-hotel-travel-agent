# P0：Onboarding 与参考材料输入

## 目的

验证统一入口能否在不调用工具的情况下完成 onboarding，并处理自然语言、图片或链接参考输入。重点记录真实抽取结果和用户确认过程，不把参考材料默认解释为“朋友的行程”，也不默认用户一定要查同款。

## 执行步骤

### 1. 新会话

输入：

```text
/new
```

记录：

- 实际回复；
- 工具调用数量；
- 事件日志中是否出现 `onboarding_shown`；
- 最终状态和判定。

### 2. 模糊意向

输入：

```text
帮我找一张去成都的机票
```

记录：

- 实际追问了哪些必要字段；
- 是否在字段不足时调用工具；
- 工具调用和日志事件；
- 最终判定：通过 / 不通过 / 未验证。

### 3. 参考材料

发送一张航班或酒店截图，输入：

```text
帮我看看这个行程
```

记录：

- 实际抽取出的字段；
- 是否询问“查识别出的目标，还是找相近方案”；
- 是否错误假设材料来自朋友；
- 用户确认前是否调用工具；
- 图片日志是否只保留引用而没有复制图片内容。
